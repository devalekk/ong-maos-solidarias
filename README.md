# ONG Mãos Solidárias

Projeto desenvolvido na disciplina de Desenvolvimento Front-end com o objetivo de criar uma aplicação web para uma organização social.

## Sobre o projeto

A aplicação apresenta informações sobre a ONG Mãos Solidárias, seus projetos sociais, campanhas de doação, oportunidades de voluntariado e um formulário de cadastro para colaboradores.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- CSS Grid
- Flexbox
- LocalStorage
- Day.js
- Git
- GitHub

## Funcionalidades

- Navegação em Single Page Application (SPA)
- Templates dinâmicos em JavaScript
- Menu responsivo
- Menu dropdown
- Modal
- Alertas e badges
- Validação de formulários
- Feedback visual de erros e sucessos
- Armazenamento de preferência no LocalStorage
- Integração com a biblioteca Day.js
- Layout responsivo
